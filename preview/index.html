    常錯的方法

      語音（台灣口音）

      這台裝置找不到台灣口音的中文語音，為了不出現中國口音，程式不會改用其他中文語音。安裝方法：
      • Windows：設定 → 時間與語言 → 語音 → 新增語音 → 中文（台灣），裝好後重新開啟瀏覽器
      • iPad：設定 → 輔助使用 → 朗讀內容 → 聲音 → 中文（台灣）→ 美佳（可下載「加強版」）
      • Android 平板：設定 → 文字轉語音輸出 → Google 語音服務 → 安裝語音資料 → 國語（臺灣）

      設定

      進度存在這台裝置的瀏覽器裡，平板和電腦各自一份。
